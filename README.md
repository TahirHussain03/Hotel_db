# Hotel Management System (MIS & Night Audit)

This project is a SQL and Excel based Hotel Management and MIS system.

## Features
- Relational database for guests, rooms, bookings, and payments
- Occupancy and availability reporting using SQL
- Revenue analysis by payment mode
- Excel MIS dashboard with pivot tables and charts
- Simulated night audit workflow

## Tools & Technologies
- MySQL
- SQL
- MS Excel
- GitHub

## Use Case
This project simulates real hotel front office and night audit operations and is useful for MIS and hospitality analytics roles.
